# BlueMap Skins 3D 3.0.0

First NeoForge release of **BlueMap Skins 3D**.

## Features
- Full-body player skins on BlueMap (optional 3D models)
- Offline markers at last logout position with greyscale + Offline label
- World-scale bodies (~1.8 blocks) and simple yaw facing
- In-map **3D** / **Offline** toggles
- Server-side only (clients do not need the mod)

## Requirements
- Minecraft 1.21.1
- NeoForge 21.1.217+
- BlueMap (NeoForge) 5.0+
